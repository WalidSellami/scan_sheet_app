# ماسح النقاط الآلي (PWA Scan Sheet)

تطبيق ويب تقدمي (PWA) خفيف وسريع، يعمل **100% بدون إنترنت (Offline-First)** مخصص للأساتذة والمعلمين لمسح رموز الاستجابة السريعة (QR Code) لأوراق وشاشات التلاميذ في المخبر والصف، مع تسجيل العلامات وفرزها آلياً وتصديرها إلى جداول Excel و CSV.

---

## المميزات الرئيسية (Key Features)

- **يعمل بدون إنترنت (100% Offline)**: يعتمد على Service Worker ومكتبات مدمجة محلياً بالكامل.
- **مخصص للهواتف والأجهزة اللوحية**: واجهة تفاعلية خفيفة للهواتف والـ Tablets مع درع واقٍ على شاشات الحاسوب الكبيرة (Desktop Guard).
- **تحكم ذكي في المسح (Controlled Scan Flow)**: إيقاف تلقائي للكاميرا عند قراءة الرمز وعرض نافذة تأكيد منبثقة تفاعلية بزر **(OK)** لمنع تكرار القراءة في أجزاء من الثانية.
- **اهتزاز لمسي صامت (Haptic Only)**: استبدال الأصوات المزعجة باهتزازات لمسية مميزة حسب الحالة (نجاح التسجيل، تنبيه التكرار، تنبيه عدم المطابقة).
- **منع التكرار الآلي (Duplicate Prevention)**: التحقق الدقيق من الاسم الكامل والقسم وتنبيه الأستاذ فوراً في حال مسح نفس التلميذ مسبقاً.
- **تصدير إكسيل متعدد الأوراق (Multi-Sheet XLSX)**: تصدير ملف Excel يضع **كل قسم في ورقة عمل مستقلة وخاصة به** مع دعم العربية (RTL) بالإضافة إلى ملف CSV بترميز UTF-8 BOM.
- **تصميم عصري متجاوب**: دعم الوضع الليلي والنهاري (Dark/Light)، ترتيب تنازلي آلي للعلامات مع تلوين دلالي (أخضر للناجحين وأحمر للمستدركين)، وإشعارات Toast كبسولية سفلية أنيقة.

---

## التنسيق المعتمد لرمز الـ QR (QR Data Format)

يتعرف التطبيق بدقة على التنسيق المنظم التالي (مع دعم الأرقام المشرقية والمغربية والعلامات العشرية):

```text
الاسم الكامل: أحمد بن علي
القسم : 1ع1
العلامة: 18/20
```

> **ملاحظة:** يدعم التطبيق أيضاً الإدخال اليدوي المباشر وصيغ JSON و CSV كخيارات بديلة.

---

##  التشغيل السريع (Quick Start)

1. شغّل المجلد عبر أي خادم ويب محلي (Local Web Server) يدعم HTTPS أو `localhost` للوصول إلى الكاميرا:
   ```bash
   npx serve .
   # أو عبر إضافة Live Server في VS Code
   ```
2. افتح الرابط على هاتفك الذكي أو جهازك اللوحي.
3. امنح إذن تشغيل الكاميرا وابدأ المسح مباشرة.
4. يمكن تثبيت التطبيق كـ PWA مستقل على الشاشة الرئيسية (Add to Home Screen).

---

## التقنيات المستخدمة (Tech Stack)

- **الواجهة والبنية:** HTML5 (Semantic, RTL), CSS3 (Modern Glassmorphism, CSS Variables).
- **المنطق البرمجي:** JavaScript (Vanilla ES6+).
- **المكتبات المحلية للأوفلاين:**
  - `html5-qrcode.min.js`: مسح وقراءة الرموز عبر الكاميرا.
  - `xlsx.full.min.js`: إنشاء وتصدير ملفات Excel متعددة الأوراق.
  - `bootstrap.rtl.min.css`: نظام الشبكة والتجاوب المريح.
